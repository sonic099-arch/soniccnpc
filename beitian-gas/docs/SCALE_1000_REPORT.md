## Ubuntu升级步骤

先在旧启动终端按Ctrl+C。在项目beitian-gas目录执行：

```bash
git pull --ff-only
source .venv/bin/activate
npm --prefix frontend ci
python scripts/dev.py
```

打开 `http://localhost:5173/import`，勾选演示数据确认后，点击“生成并加载1000口演示井”。

- 空演示库：新增1000井、335538条测量。
- 相同配置的原600井：新增400井、134214条测量，原数据保留。
- 再次点击：新增0。

若还有手工创建的井或三行导入样例，数据库总井数可能超过1000；按钮处理的是这批1000口演示井，不会删除其他井。

本地生成文件：`python scripts/generate_mock.py --count 1000 --days 14 --output work/mock1000`。

复现完整扩容及Excel验证：`python scripts/verify_demo.py --workbook work/mock1000/mock-data.xlsx --report work/scale-full-check.json`。此命令使用并清理独立临时数据库，运行数分钟。
