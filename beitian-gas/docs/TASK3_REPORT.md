| 正常自喷正确筛除、已知异常入列 | 13场景参数化单元测试与1000井逐井对照；默认列表不含可信正常井 |

| 每个异常可追溯 | 所有模拟事件检查规则版本和输入摘要；API检查原始采样ID/数值、措施ID和有效时间上下文 |
| 井号、时间、措施关联正确 | 改井号仍以UUID关联；时间及时区等价测试；措施前后采样与measure_id一致 |
| 异常合并去重 | 同类相近事件合并；两次任务指纹一致，默认只取最新1000快照，保留2000历史结果 |
| 原子失败与历史保护 | 模拟引擎内部异常整批回滚且保留失败任务；已使用规则、历史证据/复核不可改写或伪造 |

## 运行与交付范围

在WSL Ubuntu24.04内，项目目录运行：

```bash
git pull --ff-only
source .venv/bin/activate
python -m pip install --no-deps -e ./backend
npm --prefix frontend ci
python scripts/dev.py
```

已有服务先Ctrl+C停止。启动器自动迁移，不删除现有数据。打开 `/analysis`，初始化规则、勾选确认、执行分析； `/rules`发布新版本后重新执行；Swagger `/docs`提供所有请求。更多步骤见TASK3_GUIDE与README。

当前为本机同步分析演示，没有身份认证、后台队列、生产调度、现场规则标定或真实库连接。历史证据保存代表采样及输入摘要，不是完整源数据库备份。任务4的完整首页、气井列表、独立异常列表及7参数曲线尚未实施。本次未使用真实生产数据或数据库凭据。
