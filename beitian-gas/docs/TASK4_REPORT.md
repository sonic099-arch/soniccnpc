## 关键验证

- 首页计数和工区分布来自数据库聚合；空库无虚构正常井，零总数饼图不按均分绘制。
- 井号搜索转义通配符、工区/状态/类型过滤、分页无交叉重复；默认异常页按井汇总并排除正常，事件视图说明其计数单位。
- 历史任务切换、较晚窗口后回到较早窗口、部分井分析、改井号仍按UUID关联均通过。
- 七参数曲线实际生成7个SVG，原始空值、零值、缺失间隔和累计量复位保持；无采样明确提示，不生成估算值。
- 措施区间重叠及起点早于窗口仍保留；异常开始标记保持原始时间，窗口结束不含，等价时区过滤结果一致。
- 自定义曲线窗口非法、缺时区、超过90天或20000点明确返回422，避免静默截断。
- 浏览器验证首页下钻、井号查询/清空、正常井七曲线、异常证据、泡排效果不佳的措施关联、末7天切换、工区/类型/时间过滤及390像素移动页面；没有未处理页面异常。
- 证据通过原任务/异常ID读取，单井规则结果与曲线范围分开，时间范围调整不伪装为规则重算。

筛选控件采用原生单选下拉配合Element Plus表单/表格，避免组件更新递归；浏览器回归已验证。已修正测试脚本误选隐藏图标SVG、日期面板tbody等定位问题，最终测试均通过。测试库由脚本独立建立并清理，不连接或清理用户原有数据库。

## 运行方法

在Ubuntu的beitian-gas项目目录，先Ctrl+C停止原服务：

```bash
git pull --ff-only
source .venv/bin/activate
python -m pip install --no-deps -e ./backend
npm --prefix frontend ci
python scripts/dev.py
```

打开 `http://localhost:5173/`，Ctrl+Shift+R刷新，顶部应为任务4。已有1001井和正确分析结果无需重新生成或重算；首页默认最近完成任务，需要时切换历史任务。详见TASK4_GUIDE。
