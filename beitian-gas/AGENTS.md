# 长期开发约束
- 按任务1至5逐步交付；当前推进至任务4，不将占位页面表述为已实现功能。
- 后端 Python 3.12 / FastAPI / SQLAlchemy 2；生产存储 PostgreSQL；数据库变更必须有 Alembic 迁移。
- 前端 Vue 3 / TypeScript / Element Plus / ECharts，业务界面和错误提示使用中文。
- 气井以 UUID 关联，井号是可变业务编号；时间统一为带时区时间并按 UTC 存储。
- 配置、工具、措施均使用半开有效区间 [effective_start, effective_end)，空结束表示持续有效。
- 禁止将业务报警阈值写死；规则有编号、版本、配置、输入、证据、适用工况和测试。
- 未知工况和数据不足不得默认为正常；积液和冻堵只能提供有证据的辅助提示。
- 模拟参数和曲线必须标明演示性质；模拟测试通过率不能代表现场准确率。
- 修改核心算法后必须运行回归测试；测试数据库必须隔离，禁止测试清理真实数据库。
- 不上传真实生产数据、凭据或 .env；外部Git同步仅限用户授权的仓库 sonic099-arch/soniccnpc，项目位于 beitian-gas/；原有仓库根文件必须保留。
- 新增功能须补充中文运行文档，验收报告须列出总数、通过、失败及失败原因。
- 分析算法不得使用 demo_scenario、场景预期或预期标签直接决定结果，避免测试标签泄漏。
- 默认演示规模为1000井；600井旧批次扩容只能追加兼容数据，必须保留原井ID、曲线及事件，禁止自动清库。

- 分析使用固定窗口与数据库一致性快照，保留规则版本、上下文、原始代表采样及输入摘要；每次任务的WellAnalysisResult只追加，最新快照不能被更早数据窗口覆盖。
- 已使用规则与引擎结果不得通过基础CRUD改写、伪造或补挂；新规则版本显式发布并重新分析，人工复核只追加记录。

- 任务4展示页统一按明确的已完成任务读取WellAnalysisResult；默认按completed_at选最近完成任务，不混合不同窗口的最新状态快照。部分分析未覆盖的登记井标为未分析。
- 曲线只展示原始数值；保留空值、复位与采样缺口，禁止平滑或插值造成虚假正常；措施区间与异常标记以UUID和半开时间窗口关联，所有展示时间明确时区。

- Win11内网发布使用Windows入口10.86.36.43:8080，严格允许10.86.36.1–10.86.36.255；仅信任套接字对端IP，不信任客户端转发头。后端和数据库仍仅本机，禁止用可能隐藏来源的WSL端口转发替代边界检查。
- 内网使用构建静态页和本地Swagger资源，不暴露Vite；复用work/dev-postgres，不并发运行两个启动器。Windows防火墙与实际内网连通性必须区分自动回环测试和现场验证。
