# 长期开发约束
- 按任务1至5逐步交付；当前仅完成任务1，不将占位页面表述为已实现功能。
- 后端 Python 3.12 / FastAPI / SQLAlchemy 2；生产存储 PostgreSQL；数据库变更必须有 Alembic 迁移。
- 前端 Vue 3 / TypeScript / Element Plus / ECharts，业务界面和错误提示使用中文。
- 气井以 UUID 关联，井号是可变业务编号；时间统一为带时区时间并按 UTC 存储。
- 配置、工具、措施均使用半开有效区间 [effective_start, effective_end)，空结束表示持续有效。
- 禁止将业务报警阈值写死；规则有编号、版本、配置、输入、证据、适用工况和测试。
- 未知工况和数据不足不得默认为正常；积液和冻堵只能提供有证据的辅助提示。
- 模拟参数和曲线必须标明演示性质；模拟测试通过率不能代表现场准确率。
- 修改核心算法后必须运行回归测试；测试数据库必须隔离，禁止测试清理真实数据库。
- 不上传真实生产数据、凭据或 .env；不配置外部 Git remote，除非用户明确授权。
- 新增功能须补充中文运行文档，验收报告须列出总数、通过、失败及失败原因。
